# Roadmap

1. Baseline verified on Archipelago 0.6.8 and Silksong 1.0.30000. Seed `12345` generated solo and two-player worlds, and the client smoke test covered sending a check, receiving an item, saving, and reconnecting.
2. Reachability audit for Red Memory and The Mist verified on Silksong 1.0.30000. Fixed `RedMemorySkip` transition caching (`ToFsmState`) and suppressed the vanilla Everbloom `CreateUIMsgGetItem` popup when Everbloom is shuffled, verified automatic return to `Tut_04` (`door_ritualEnd`), and verified the `Abyss_05` flower gate before and after Everbloom delivery (`Last_Dive`). Kept the one-Silkheart requirement for The Mist after confirming Needolin requires `Silk >= 1`, drains Silk per use, and several Mist rooms have zero enemies. See [Development](DEVELOPMENT.md#the-mist-and-red-memory).
3. Map tracker filters and reachability hints verified in game. Universal Tracker matched all 13 reachable checks at one progression snapshot on seed `12345`. See [Development](DEVELOPMENT.md#map-tracker-smoke-test).
4. Expand shuffle coverage. Experimental soul, entrance, and traversal modes passed Act 1 generation. The combined interior preset passed an Archipelago server restart and a controlled five-flea Silksong test covering item delivery, offline save load, a coupled doorway, and goal reporting. Next, play seed `54321` from a fresh save and verify Mossgrub soul gating and the five-flea goal through normal gameplay. See [Development](DEVELOPMENT.md#next-playtest).
5. Own the player workflow. Ship matched plugin and APWorld releases with first-party installation, hosting, compatibility, and recovery guides. Cover common stuck states and the return from Act 3 to Act 2 with verified instructions. Replace upstream setup redirects in the README and site as first-party coverage lands. Preserve upstream credits.
6. Build a first-party YAML generator from the shipped APWorld options and defaults. Support presets, validate incompatible settings, and verify exported YAML by generating representative solo and multiworld seeds.
7. The site redesign, branching setup checklist, and GitHub short description are in place. Script checks covered host and join branches, local progress, and reset. Verify the full setup flow on a clean browser profile once the first-party downloads and YAML generator are available.
8. Cut 1.0 once supported goals and presets pass the baseline, progression blockers are triaged, tracker behavior is documented, and players can install, configure, and troubleshoot the release from first-party resources.
